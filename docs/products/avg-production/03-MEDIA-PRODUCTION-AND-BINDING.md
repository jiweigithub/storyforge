# AVG 媒资需求、真实生产与自动绑定

> L2 · 版本：1.12.0 · 生效：2026-10-17 · 受 [AVG 产品契约](../AVG.md)约束。
> 目标合同覆盖从用途/参考到实际字节及消费者；当前只有 Prompt/文本锚点的路径不能宣称参考生图或配音已实现。

## 1 需求先于生成

每项需求先声明给谁用、为何用、需要哪些事实与参考，再选择能力和生成/导入路径。通用 `ProductMediaKind` 的九类继续使用；同为 ui 的物品图标与菜单装饰不能因此具有同一消费者。

目标 `AvgMediaRequirementV1` 的逻辑字段：

| 字段组 | 必需语义 |
|---|---|
| identity | requirementKey/revision、familyKey、subjectKey、用途/消费者和准确上游工件 |
| purpose | mediaKind、消费 domain/slot、场景/句/状态/语言，required、允许 fallback 及其艺术影响 |
| content | 公开事实、情绪/行为/信息目的、必要细节、禁止变化和禁止泄露 |
| visual/audio brief | prompt/negative、尺寸/比例/alpha、安全区/锚点，或 duration/loop/channel/混音/配音版本 |
| references | 真实已授权参考的 asset/hash/revision、角色、使用目的和允许变化；非纯文本描述 |
| production policy | generate/import/reuse/edit、所需能力、数量/尝试上限、数据发送政策、权利与费用约束 |
| acceptance | 技术检查、家族一致性、实际消费者尺寸/连续场景、专业/作者审听查看要求 |

系统生成 owner、实际 hash/版本/成本/receipt。需求的 prompt 是生产输入，不能冒充候选图片、配音或已消费证据。

## 2 媒资家族与用途

| 家族 | 典型产物 | 消费者和连续性要求 |
|---|---|---|
| 人物基准参考 | 身份/服装/比例/配色、必要转面或特征基准 | reference-only；被后续生产实际消费，不能默认上舞台 |
| 角色立绘 | 同人同服装的姿态/表情/状态、必要差分与 alpha | stage actor；对齐锚点/尺度/轮廓，换表情不漂移身份 |
| 对话头像 | 指定裁切/朝向/表情与显示身份 | dialogue avatar；不是缩小整张立绘塞进任意框 |
| 物品/证据图标 | 可辨轮廓、状态和选中/不可用视觉 | inventory/case list；按冻结设备实际小尺寸查看 |
| 物件详情 | 与 icon 同物件的细节/可观察状态 | evidence detail；可读文字由合法 UI 数据，图不能发明真相 |
| 场景背景 | 同地点/机位的昼夜/天气/事件状态、角色站位空间 | stage background；地理/消失物与光源保持合法 |
| 关键 CG | 剧情动作关系、视角、人物/物件/环境组合 | stage CG 或 gallery；事后鉴赏按实际解锁 |
| UI/菜单装饰 | 框/面板/按钮皮肤、安全区、状态与主题 | menu/dialogue/inventory 的明确槽；可访问性文字由 UI |
| 地图/档案/关系板 | 正式地点/事实的可视结构与装饰 | archive/location/case-board；只投影当前允许信息 |
| BGM/变奏 | 主题、情绪转折、循环段与静默 | music channel；衔接和循环须在场景中审听 |
| 环境与 SFX | 连续环境、一次性动作/反馈、必要变体 | ambience/sfx channel；持续与瞬时不混，关键事件有准确触发 |
| 配音 | 定稿台词、人物/语言/演法对应 clip 或带可靠对齐的片段 | dialogue voice；实际音频、句匹配、读音/表演与连续对白 |
| 高级层/动作/视频 | 分层角色、特殊特效/视频等能力特定产物 | 后置明确 renderer/恢复合同；不在首场景默认采用 |

封面/商店宣传是 marketing 用途，可以复用授权且信息合法的主体，但不能自动加入 runtime 资产闭包。视觉参考也不因为“被生成器使用”而自动成为作品可公开内容。

家族先冻结主体基准及允许变化，再生产必需变体。每个候选记录 family/subject、参考版本及加工 lineage；作者改身份基准使相关变体 stale，不使无关地点背景全部重生。

## 3 真实参考与 provider 请求

目标 `ProductMediaRequestV2`/AVG 适配扩展保留 V1 文本路径，新增真实参考和 voice 所需类型化输入。公共字段必须有 AVG 与另一真实调用方需求证据；否则留在 AVG adapter，不能扩大中立世界协议。

每个 `ReferenceInput` 指定 assetRef、contentHash、MIME、字节/受控读取句柄、purpose（identity/pose/composition/style/detail）、crop/mask（如能力支持）、授权与数据分类。模型看到的文字“角色 A 基准图”不是参考传输成功。

运行前冻结 capability snapshot：provider/model/endpoint、支持的输入/用途/格式/尺寸/alpha/mask、数量与文件上限、async 状态/查询机制、计费上界、授权/数据政策及实际账号可用性。官方文档能力与当前账号可调用性分别取证。

传输回执保存实际送入参考的 hash/处理版本、参数、operationId、已知费用/用量和实际返回。provider 不支持某参考类型则拒绝或返回作者改路径；不丢参考继续文本生图后称身份受控。

结果未知时先查询既有 operation/receipt；无法判定则停在未知，禁止自动再发一笔。网络瞬断、有界重试、授权/余额/4xx 和单次计费分别按 Harness 处理。收费尝试、参考处理和废弃候选都计入成本；无价格/用量证据不记零。

研究中列出的参考生图/语音接口仅是技术候选，本设计不锁定供应商、报价或商用效果。[研究记录](../../audits/AVG-PROFESSIONAL-METHODS-20261013.md)中的非商用研究代码不能作为商业默认生产底座；外部服务的权利需按实际输入、账户/套餐和输出条款核验。

### 3.1 开工前复核的接入基线

2026-10-14 对当前仓库的核对只描述本项目接入，不据此限制服务商的全部能力：

| 项 | 当前代码证据 | BASE-01/02 的验收缺口 |
|---|---|---|
| Agnes 图片 | `agnes.image-2.1-flash.v1` 只有 generate、每次 1 张；实际 body 为文字 prompt、1K/ratio、base64 返回 | 真实参考字节/crop/mask/edit 尚未传输，不能靠描述参考图判作身份受控 |
| 异步结果 | 当前图片路径接收带 data 的完整响应；task_id 只作为元数据/请求标识 | 尚无只返回 operation 的查询/恢复闭环，结果未知不能重新 POST 掩盖 |
| 费用 | candidate receipt 保留 usage/costUsd；estimate 的现金可以为 null | null 为未知；需要实际账号/路由/计费证据，授权无总上限不使未知变零 |
| 配音 | 公共 V1 媒体类别是 image/music/sfx | voice 的文本/演法/真实 clip 和能力/权利回执仍待 BASE-02，不借 BGM 冒充 |

依据为 [`media-adapters.ts`](../../../src/lib/product-production/media-adapters.ts) 的请求/响应合同及 [`media-transport.ts`](../../../src/lib/product-production/media-transport.ts) 的连接检查；本轮未读取凭据或调用 provider。Agnes [官网](https://agnes-ai.com/)的公开功能宣传不构成所需参数、当前账号可用性、实际费用或 AVG 家族质量证据；具体端点/模型应在 BASE-01 的小批次前重新冻结，不静默替换作者路由。

### 3.2 当前接入增量（2026-10-16）

AVG 专用 adapter 已支持已授权 Work-owned 参考的真实 Data URI、用途/允许变化/顺序和 1K/2K 档位；crop/mask 仍拒绝，alpha 仍须实际检查。默认关闭的实验性 V2 共享服务已接明确开始、固定路由 hash、有界预算/Run、解析前原始响应、严格 producer 接收、独立作者选图与最终演出确认。原图已全部接收后可离线继续组装；备份 remap 与恢复会话已在受控浏览器验证。范围和未完成项以[实施计划 §1.3](../../roadmap/AVG-IMPLEMENTATION-PLAN.md#13-当前媒资自动生产目标2026-10-16)及[工作包 §3.3](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#33-base-01b-的实验性共享服务链路)为准。

工程验证使用原创 PNG 和拦截的 HTTP，不是实际 Agnes 调用或家族艺术验收；默认关闭的工作台增量已接需求表单、合法参考授权、原图/选图确认和演出配置，见[工作包 §3.4](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#34-base-01b-的工作台增量)。同一冻结批次的失败恢复已接明确保留原图、子版本零调用复验和仅重做未保留项，含连续返修与备份 remap；必须重新开始及采用，不继承未知请求的重发权限，见[工作包 §3.7](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#37-base-01b-的明确原图保留与局部重做)。已采用生成图的后续参考见 §3.3；作者家族方案和跨批演出原图继承见 §3.4。本地裁切/画布加工与衍生来源见 §3.5；专业语义加工、视觉岗位及真实 TTS 尚未完成。当前确定性 stage/item 槽配置不表示目标 `AvgMediaBindingV1` 的全部 provenance/版本/返修合同已落地。

### 3.3 已采用生成图作为后续参考

实验性图片工作台可从当前 Work 的已采用生成图中核验、查看并选择后续参考。每次用途、允许变化、向本次供应商发送和衍生使用均单独确认；采用原图不自动授权后续外发。已封存预览先显式选择准确修订基线并保存，再编辑下一批需求和准备新版本；未封存批次先明确停止并准备新版本，再调整需求。保留失败批次原图的恢复方案仍走 §3.2 的独立合同。

`AvgMediaReferenceV1.generatedSource` 是可选的严格便携来源，绑定 productionKey、原图的准确 Build/Brief/Plan/epoch/producer 证明，以及作者选择的版本/hash/采用回执，不保存本机 ID。未声明此字段的旧参考 JSON/hash 保持；已声明的生成来源不能退回同名导入记录。系统复验实际开始命令、作者采用、原 HTTP 或零调用复用谱系、同 Work 字节和真实解码，再发送准确 Data URI；来源纳入请求 inputHash 和本地传输回执。身份参考必须属于目标主体；同一家族的身份基准版本变化时，必须明确采用新基准。

本增量不创建假导入记录或第二套媒资库。来源及 Blob 随既有 Work/Build/工件注册表完成备份/remap，历史只读验证不恢复旧 Run 或采用权限；原版本、候选与账单保留。超过当前 8 MiB 参考上限的原图明确拒绝，不能隐式缩放。参考授权不会使原图自动进入下一版本的演出或公开目录。具体工程证据与未完成的家族/加工/专业质量范围见[工作包 §9.1](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#91-avg-04a1-已采用生成图的后续参考)。

### 3.4 作者家族方案与跨批舞台原图

实验工作台以严格 `AvgCharacterFamilyPlanV1` 保存作者声明的基准、同一人物/家族/基准修订、身份造型约束、共同尺寸/档位/alpha，以及 1～8 个准确姿态或表情变体。提案绑定准确来源输入与审阅时草稿；确认本批全部外发/衍生用途后才保存到既有 `mediaBatch.characterFamily`。修改重置提案和授权，服务重算 hash 并比较逐项确定性请求；保存/核对不调用。既有登记 Skill、开始授权、有界尝试、原图/作者选择/独立舞台采用继续管执行。作者方案不是新专业 AI 岗位或艺术通过回执。

多批生产可在新作者舞台保存 `inheritedImages`：准确旧 Build/Brief/Plan/producer 和作者选择来源，不能指向当前/未来 Build、reference-only、其他作品/冻结世界、损坏字节或伪元数据。来源只是待核对提案，新版本仍须确认演出；组装器以原 Blob 生成本版本媒体工件，保留原来源和新采用回执，不冒充导入或重生成。同 key 新图也必须先核实旧来源和当前作者选用，再替换编辑草稿。明确结束批次需求后可以不带图片能力和密钥重组 V1；旧调用、未知费用、候选和 Build 保留，不能因此重发旧未知请求。

上述字段都是可选严格结构；缺省时保持旧字节/hash，不增加表或迁移。媒资归 AVG Work，世界只读，沿用既有表注册生命周期与便携 hash/回执来源。原图大于 8 MiB 只禁止供应商参考输入，不禁止合法本地舞台复用；不会自动缩放、裁切或抠图。完整来源/删除图、历史家族目录、专业角色/工具和真实家族艺术观察另验，当前证据见[工作包 §9.2](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#92-avg-04a2-作者人物家族与多批次演出继承)。

### 3.5 明确本地加工与衍生来源

实验 AVG V2 可在作者工作区保存独立 `imageProcessing` 配方方案，准备方案/明确开始时与 Brief/Plan 一起冻结；它不进入供应商原始需求。原图 → 本地零调用加工 → 作者视觉评审 → 选择 → 演出是固定依赖。旧 V1 和省略该字段的 V2 不增加任务或改变 JSON/hash；无加工策略不能夹带衍生选择，有冻结加工时不能跳过它选原图。原始请求、响应、账单和原 Blob 保留。

当前本地能力为有界裁切、等比 contain/cover、画布/锚点、透明留边或明确 RGBA 底色，输出 PNG；不做隐式拉伸、自动抠图、面部修复、mask 或供应商 edit。裁切是原图万分比坐标，cover 在源范围内取样，不创建无限中间画布。输入 32 MiB、解码/画布 16M 像素、单边 4096 的输出边界及原生解码/编码超时由代码执行；已知不符合需求尺寸/画幅，或透明需求配不透明底色，在收费开始前拒绝。已有透明像素可保留，透明留边不能证明主体边缘已抠好。

加工 task 是登记原生 Plan 的 deterministic Run，单次、零 model/media/cash 调用，预算另记本地耗时/储存。回执冻结 processor 版本、准确原图 hash/尺寸、配方 hash、实际取样/目标几何、PNG/hash/像素观察、alpha 和浏览器；由共享 Harness/producer checkpoint/ledger 接收独立 `avg.media.processed.<key>` 工件与 Blob。原图及加工图有各自准确 producer 回执，不把本地处理伪装成供应商响应。失败保留原图和零调用失败证据，不自动重试。当前分支工程验证与保留边界见[工作包 §9.4](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#94-avg-04a4-本地加工衍生选择与真实像素消费)。

V1 选择合同继续只准原图；显式 V2 选择同时绑定准确 raw 与 processed revision/hash。评审绑定实际将选用的加工图，原图意见不能冒充对新图的查看。采用、当前/冻结编译、生成参考及舞台继承复验原图 producer、加工 Run/配方/字节和作者输入依赖；不能以同名导入代替。已采用小图可按新用途另外授权参考，8 MiB 输入上限仍按实际发送图计算。备份/remap 保留便携来源和两份 Blob，不重编码恢复；Work 删除/垃圾回收沿既有注册表。

改变配方需明确新 Build；保留的原图可在零供应商调用的子版本中按新配方重新加工、评审和选用。旧加工图/旧意见不能取得新用途授权；被否决选择留下的草稿位置，只能在核实准确父原图或加工来源后由本批已采用新图替换，不能变成 V1 继承授权。专业美术加工、语义遮罩/抠图、完整跨历史来源/删除目录和艺术校准继续后续。

### 3.6 专业方案与确定性需求编译（目标，尚未实现）

作者手填的家族方案和 S2 会谈不替代 S3 的专业视觉岗位。专业路径先冻结主体/消费者目录、已确认事实、合法参考及发送边界、画幅/能力和有限批次，再由独占写域的岗位提出视觉基准与逐主体媒资 Brief；语义输出成为待作者确认的工件。代码在准确已采用的上游版本上编译具体需求，验证槽/主体/参考权限和数量，生成请求与输入 hash，然后才允许原有生成、评审、选图与组装链执行。模型不能选择别的 Work、改写台词/规则、授予许可或自报版本/质量通过。

现行 V2/V3 的完整图片请求在开始前已经冻结，专业方向不能原地覆盖它；接入必须显式升级 AVG 私有合同和实际调用方，旧版本的字节/hash、恢复与原图来源保留。新模型调用只取得其任务必需的已登记投影；向图片供应商发送参考的许可不自动扩展到另一个策划/视觉模型。专业视觉 reviewer 必须实际收到可观察图像及准确基准；缺图、缺能力或连续场景未观察时保留 unknown，作者视觉问题记录继续有独立作用。

按“合同与岗位基础 → 单主体的方案采用/需求编译/真实消费 → 按需人物、地点、物件家族及可观察评审”逐增量交付，不要求先完成专业故事或全部 22 岗位。每增量的正式闭包、失败/备份与完成门见[工作包 §9.5](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#95-avg-04a5-专业视觉方案与需求编译待施工)；合同名称或受控测试不代表专业艺术和真实账号校准已经通过。

## 4 候选、加工与采用

生产阶段：需求冻结 → 主体参考确认 → 能力/预算/数据授权 → 真实生成/导入 → 字节检查 → 有界加工 → 单项/家族/合成评审 → 作者采用 → typed binding → Build 验收。

| 阶段 | 保存证据与失败处理 |
|---|---|
| 返回候选 | 原字节/hash、请求/Run/operation、技术 metadata、权利及成本；空字节/坏格式不转为成功 |
| 加工 | 裁切/缩放/alpha/音频裁段或响度处理的工具/参数、input/output hash；保留原候选，不原地覆盖 Blob |
| 技术审查 | 尺寸/MIME/alpha、可解码、声道/采样/时长/截断/循环；检查结果不等于艺术通过 |
| 专业审查 | 真实图/音与准确参考、身份/比例/轮廓、姿态/光线、读音/表演/混音、实际小尺寸与连续展示 |
| 作者采用 | 看/听准确候选及费用，接受或拒绝；采纳的是版本/hash，不是“以后自动生成的图片” |
| 复用 | 相同合法字节可共享 Blob；用途、可公开信息和绑定仍单独验证 |

图标目标尺寸由设备 Brief 冻结，可先以 32/48 px 为测试点；这只是拟定观察尺寸，不能宣称已达清晰度。立绘透明边缘、脚/视线锚点和文字安全区要在最终舞台中检查，不能只看单图大预览。

无 alpha 的候选只有声明允许背景或经合法处理后才能进入透明立绘用途。当前特定 provider 的抠图路径不自动适用于所有生成器、参考物件或图标。物品可读编号/邮戳/日期等由正式状态与 UI 文本呈现，不能让生图错字修改剧情。

缺观察能力的 reviewer 只能给技术/文本意见，艺术项为 unknown，转交可观察模型或人。身份漂移、知识泄漏、物件状态错误及关键配音错句是 blocking；不能用其他好图/高分抵消。

在完整工厂前，CAL-01 分别查看一个必要人物/物件家族和短对白的真实输入/输出、用/废率、修图/修音/审听与费用。不能只记参考接口“可调用”便扩大，也不能等所有专业岗位/编辑器完成才发现基本身份/演法不可用。若目标需专业人工画图/加工/录音，可作为明确授权的 import/edit 候选，记录实际工作/权利/费用并走同一 typed adopt；人工后的成绩与原始自动生成成绩分别报告。

### 4.1 当前作者视觉观察与问题交接

新工作台和作者家族批次冻结可选 `author-visual-v1` 策略，将“原图 → 作者视觉问题记录 → 作者选图 → 演出”编成同一有界 Plan；无该字段的旧批次和采用协议保持。观察记录使用既有 `review-issues` 工件、pending 候选和 `adopt-avg-artifact` 命令，不新增表、迁移、AI 调用或世界写入。评审消费 Run 只证明消费了这份作者输入，recorded gate 不表示艺术通过。

界面并列显示准确原图及参考，提供透明底和物品图标 32/48 像素观察；原字节没有加工。作者分别记录身份/造型、参考连续性、构图/完整性、可辨认性和透明边缘的可用/失败/未知/不适用，以及本次观察依据。当前需求必需项不能写不适用；无身份/连续性基准不能记相应通过。未显示的原图和参考不会由界面伪造已观察；后端重复核验同 Work、冻结版本/hash、实际字节和解码，尺寸/比例/透明硬失败须记录 blocking 或未知。

未知和 blocking 可以保存并确认成独立问题记录，原图、账单与历史意见保留；存在它们时不能选用。每个失败项绑定准确位置、证据、media owner、允许返修范围、影响和重验条件。解除既有未知/blocking 结论需要新的依据说明。修改未消费的评审会使旧选择及演出失效；已被执行消费的评审必须新建 Build，可通过既有原图保留合同零调用复验，再独立评审/选用。原作者证明、当前/历史编译、生成参考和旧图舞台继承都闭合这份精确评审依赖，备份/remap 不补造意见或恢复执行。失效选择对应的编辑图片只能在核实原始 producer/元数据/字节后，保留为同一新批次必须重新选用的草稿占位；它不取得旧图继承或零调用 V1 使用权。

这些是作者对已展示输入的观察记录，不是专业 reviewer、独立模型、真实目标玩家或商业作品结论。本地裁切/画布加工与衍生来源见 §3.5；专业加工/视觉岗位、真实账号费用和连续艺术观察仍在后续。评审本身不自动修图或重新请求。当前工程证据见[工作包 §9.3](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#93-avg-04a3-作者视觉评审与返修问题交接)。

## 5 配音生产合同与播放交接

配音需求以正式台词绑定：lineKey、speakerKey、locale、textRevision/hash、performanceRevision、voice preset/version、发音词典、言语行动/情绪原因、前后句及速度/停顿/强调边界。演法版本与文本版本分开：改字使旧音频 stale；同字不同演法生成新 clip，不能覆盖旧 release。

voice preset 保存合法来源、可用模型/语言与权利范围；不默认克隆演员、用户或第三方声音。配音主体与字节留在 AVG 产品层，世界只提供人物语义。旁白、别名、部分配音的范围必须在 Brief 中声明，未覆盖句按允许静音政策运行。

| 产物形式 | 采用条件 |
|---|---|
| 单句 clip | 实际音频与准确句/文本匹配；读音/演法/首尾/连续接话审听 |
| 多句/对话片段 | 有实际可验证的逐句 timing/边界和 speaker 对齐，或作者只按整个片段消费；不能根据字数猜切点 |
| 片段裁切 | 保留原音频与裁段工具/边界、真实对齐来源和输出 hash；切错/漏字/串人物拒绝 |
| SSML/情绪参数 | 仅发给该 model/voice/locale 确实支持的能力；不假定所有 voice 支持同一 style |

采用音频记录 duration、codec/声道、必要 timing、文本/演法/音色版本、技术/艺术/人类观察和成本。实际 audio ended/abort/error 交给播放协调器；播放开始回调不等于播放完成。

voice、music、ambience、sfx 分用途音量/混音；BGM/环境循环、一次性 SFX 叠加上限和对白可懂度在连续场景检查。换句、回听、快进、读档及离开播放器取消旧 playback generation；后台政策和失败结果见[系统规格](02-SYSTEMS-AND-RUNTIME.md)。无浏览器声音权限时显示必要操作，不默默等到超时。

### 5.1 已采用配音的跨批沿用（施工中）

作者明确结束已完成或已停止的配音批次时，可在编辑演出中保留准确已采用音频的 `inheritedVoices` 来源提案。它绑定原始 producer/请求、原审听与作者采用的便携回执，实际来源仍须核验原授权、Plan、响应、同作品 Blob 和真实解码；不造导入别名，不恢复旧 Run 的执行权，也不把旧选择自动采用进新 Build。可选字段缺省保持既有数据形状和 hash，无新表或迁移。

后续批次只生产本次明确选择的新句，沿用声音仍逐项绑定准确原句、说话人、场景、语言和原音色/演法来源。改字或换说话人不能继续沿用旧音频；需要重配时先明确移出该音频及逐句绑定，再准备新需求。无关句的变化可以保留原音频，但当前演出仍须确认，完整播放与本地版本门仍单独验收。

来源预览展示原句、原版本、音色和权利依据并读取真实原音频；这些声明不会自动变成商用许可。结束批次不删除原响应、候选、费用、Blob 或旧存档，不移除未知结果防重。当前合同及真实 Harness 已验证完成/停止后沿用、原作者证明、篡改拒绝、零新调用和原字节复用，类型、lint 与构建通过；受控 HTTP/解码不代替原生播放，原生跨批、本地 Release 与便携来源用例仍待验证，不能据此宣称该流程已经交付或已完成真实 TTS 校准；详见[工作包 §4.16](../../roadmap/AVG-WORK-PACKAGE-CARDS.md#416-已采用配音的跨批沿用与明确结束批次当前施工未验收)。

## 6 typed 消费绑定与自动配置

目标 `AvgMediaBindingV1` 字段：bindingKey、requirementKey/revision、subjectKey/familyKey/variantKey、consumerDomain/consumerKey/slot、scene/line 或 event（适用时）、locale、state/visibility condition、layout/anchor、required/fallback、assetKey/blobHash、采用/处理/上游 revision。

`consumerDomain` 是 AVG 闭集：stage、dialogue、inventory、evidence、menu、gallery、archive、marketing、reference。各域有独立受校验的 consumerKey/slot，不用通用字符串打开任意组件。

| 示例需求 | 正确自动配置 | 必须拒绝的配置 |
|---|---|---|
| 信封 icon | inventory item 图标槽，状态/可见条件对应正式物件 | 当作 ui 一律 set-overlay，遮住整张舞台 |
| 信封 detail | evidence 详情槽，未开封可观察信息与公开文字 | 详情直接展示尚未获得的信中秘密 |
| 人物表情 | stage actor 指定主体/外观/锚点 | 只按图片数组顺序猜人物和左右站位 |
| 人物头像 | dialogue avatar 指定说话人/显示身份 | 把 reference-only 人物基准当成公开头像 |
| 背景/CG | 指定场景/事件、舞台槽、视角和导演时序 | 绑定不存在 Beat，或每张图都展示一遍假装覆盖 |
| 逐句 voice | 准确 line/text/演法/语言的 dialogue clip | 同 beatKey 但文本已改，仍沿用旧对白 |
| 菜单/鉴赏 | 合法 menu 槽或已解锁 gallery entry | 为消除 orphan 把宣传图/锁定 CG 强塞剧情 |

自动绑定读取已采用需求、目录、导演与实际候选，在确定性 service 生成可预览提案；作者确认后进入 Build。唯一正确映射可自动填充，冲突/缺口必须明确定位，不让模型在 release 阶段猜。自动配置不等于自动发布。

组装覆盖检查从实际 consumer catalog 出发，包括非舞台菜单/库存/详情/鉴赏；stage Cue 的 orphan 检查不能取代全消费覆盖。必需 slot 缺失、wrong kind/MIME、跨 Work、stale 参考/文本、冲突绑定或禁止信息阻止 Build；可选缺失有可见、已批准的 fallback。

reference/marketing 不纳入 runtime 必需闭包；runtime 只冻结实际需要且允许公开的 Blob。未解锁 gallery 的资源访问遵守展示/公开边界；本地离线包不能当作加密防剧透能力，分发时记录可提取边界。

## 7 局部返修与证据

| 修改 | 最小失效与重验范围 |
|---|---|
| 某句文字 | 同句的 voice/字幕/对齐与依赖该文本的演出；其余不相关 BGM/背景可保留 |
| 人物基准/服装 | 家族的相关立绘、头像、CG 与合成；不影响无关人物和地点 |
| 物件状态/公开事实 | 对应 icon/detail/特写、条件/可见 UI 与路线消费；不得只换图不改规则 |
| 背景机位 | 该场构图、站位/CG、热点坐标和文字区；角色身份基准可复用 |
| 音色/演法 | 对应 voice family/句段、混音及等待策略；文本不因换声音自动重写 |
| consumer/规则 | 重新校验绑定、覆盖与可见性；合法 Blob 可保留，但旧 Build 验收不复制 |

返修创建新需求/候选/hash，记录保留/拒绝、费用及原因；作者锁定项遇到冲突返回裁决，不能绕过 stale。旧 release、Blob 和旧档仍使用旧输入；修复版另行冻发布并复测旧档。

技术接入点：`src/lib/types/product-media.ts`、现行媒资 gateway/transport、`src/lib/product-production/production-executor.ts`、AVG adapter、Blob/import service 与 runtime validator。开工卡负责复核实际符号/调用方；不得将整个媒资系统改成 AVG 专属或在组件中另建生图/TTS 调用。
