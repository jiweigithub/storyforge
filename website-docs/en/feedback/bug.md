# Bug report

Provide a reproducible description, steps, and expected result where possible. Remove API keys, tokens, passwords, and other sensitive information before attaching screenshots or logs.

In v4.0.2, use General settings → Problems and suggestions → Report a problem (报告问题), fill in the details, and confirm sending. In-app feedback enters a private maintainer inbox. Feature suggestions can also be submitted without a crash. Preview the failure summary and choose whether to attach it; see the [instructions](/en/guides/troubleshooting#problems-and-failure-reports-in-downloaded-builds).

**The web form below creates a public GitHub Issue.** When using “Open official feedback form with summary”, inspect Additional information and remove anything you do not want public before submitting. See the [client User Agreement](/en/guides/privacy#in-app-feedback-and-usage-reporting-in-development) for privacy information.
