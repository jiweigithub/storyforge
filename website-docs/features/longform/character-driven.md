# 角色驱动剧情

入口：长篇工作台 → 角色驱动。用于从人物欲望、矛盾和变化推导剧情，再把选定方案用于大纲或后续创作。

## 开书规划与改稿

开书规划用于建立人物弧光与剧情方案；改稿路径用于已有作品的调整。开始前明确是在探索一个可能方向，还是决定替换既有规划。

角色卡提供人物当前信息，弧光方案表达人物将怎样变化。不要把方案中尚未发生的未来状态，直接当作角色已经具有的事实。

## 管理多个方案

可以新建方案、复制为新版本、重命名并切换查看。浏览某个方案与启用它不同：

- “设为当前参考”明确决定后续大纲与正文 AI 是否参考该方案。
- “后续 AI 正在参考”表示当前活动方案。
- 切换浏览不会自动把所有候选都作为当前参考。

需要比较不同人物走向时，先复制为新版本，再修改，保留选择依据。

## 从角色到卷章

添加角色，检查从角色卡带入的信息，完善人物弧光及额外要求。生成后核对角色选择与事件之间的因果，再检查卷章候选。

采纳到大纲和设为当前参考是不同操作：前者改变选定的大纲内容，后者控制后续生成参考哪一份方案。不要以为点了其中一个就完成了另一个。

## 角色候选修改后不能采纳

在角色卡的补全或状态调整中，先检查候选，再修改并明确采纳。必填内容被清空、超长或修改保存失败时，候选面板会显示原因，并暂时禁用“采纳”，避免把上一次成功保存的内容误当作本次修改。

修正内容并保存成功后，再检查候选并采纳；也可拒绝当前候选。不要用重新生成覆盖尚未核对的结果。内容已变化导致的过期提示仍需按当前角色资料处理；这项保护不自动改变角色状态。

## 与现有正文的关系

已有章节是已经写下的事实。新的角色弧光若与正文冲突，先决定修订范围，再使用改稿与影响检查处理后续章纲和状态。

这项功能辅助规划人物驱动的事件，不保证自动生成自然可信的心理变化。作者仍需判断：行动是否来自人物自身、转折是否有足够铺垫。
