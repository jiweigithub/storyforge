# 分步骤长篇

适合长篇小说、网文和持续连载。当前工程主链已完成；AI 的文学质量、费用与长期效果仍需要作者审校。

入口：“长篇 → 作品库 → 新建长篇”。长篇拥有自己的作品资料和正文，独立世界引擎不是前置条件。

## 从想法到第一轮成稿

1. 在“作品概况”明确名称与创作目标。
2. 在“灵感与参考”整理想法和参考材料；已有小说可走[文档导入](/guides/import)。
3. 在“故事设计”明确核心冲突、主线与创作规则。
4. 在“人物与关系”建立关键人物及其动机；按情节需要补世界和地点。
5. 在“大纲与章纲”安排卷与章节，在“场景细纲”把本章拆成可写的行动。
6. 在“正文”写作、生成或修改；检查候选并决定是否采纳。
7. 整理本章带来的事实、角色状态、伏笔与故事线变化，再进入下一章。
8. 在“版本与导出”保留正文与完整备份。

## 工作台各区域做什么

| 区域 | 保存什么 | 什么时候使用 |
| --- | --- | --- |
| 灵感与参考 | 灵感、原作与参考分析 | 构思前、需要补依据时 |
| 世界与设定 | 规则、环境、社会与历史 | 故事需要稳定背景时 |
| 故事设计 | 故事核心、创作规则 | 写大纲前以及主线改变时 |
| 人物与关系 | 人物档案、角色关系 | 确定人物或角色发生变化时 |
| 大纲与章纲、场景细纲 | 全书结构和章节任务 | 写正文前、调整后续走向时 |
| 正文、改稿影响 | 实际手稿与变更影响 | 日常写作和修订 |
| 伏笔、事实、状态、物品、年表 | 已发生内容及其连续性 | 章后核对和续写前 |
| 文风学习、提示词 | 写作偏好与任务要求 | 调整生成风格时 |
| 版本与导出 | 历史版本、正文和备份 | 阶段定稿、换设备前 |

这些区域按需使用。写现实短场景不需要先填写力量体系；没有多世界情节时也不需要开启多世界。

## 挑选当前要写的部分

可以从一个已确认的最小想法开始，也可以只写指定卷、章、正文片段或人物字段。向创作助手说明“只补人物动机”“先写第三章，不改世界”等范围；检查执行计划后确认，不必先补齐所有设定。

候选支持阅读、编辑、继续讨论和明确拒绝。拒绝某项可选工作不应迫使你完成它；章后可选整理失败时，已采纳正文仍保留，可按提示单独恢复。作品库字数依据已保存正文显示，生成中的草稿不等于已保存字数。

## 自由讨论与试写

炉娘的“交流方式”可以选择“自由讨论 / 试写”。先聊设定、随机写一幕或比较不同版本，不必填写全部资料，也不必先创建章节。可选择世界观、角色或故事核心作为本轮参考；未选择的资料不会被当作已读全文。

回复保留在本作对话中，不自动修改作品。点击回复旁的“提取为设定候选”，选择分类，再点击“AI 从内容拆分词条”：检查来源原文和候选，确认“写入所选”后才保存为正式词条。已有候选可在同一作品、同一分类恢复，刷新不会重发模型请求。需要执行创作任务时切回“讨论与规划”，检查计划再开始。

正文中的“设定查询”保留查找与阅读；写作对话统一打开炉娘。旧版未标记作品归属的问答历史只在你点击查看后展示，可先导出原文件，再确认是否属于当前作品。认领会复制记录，原始历史保留，不会直接写进正文或设定。

## 炉娘与语音

创作面板中的助手现名为“炉娘”。打开“助手与语音设置”，可调整显示、形象和语音方式。

- 语音识别结果先进入可编辑输入框，检查后再发送，不会自动执行计划或采纳候选。
- 可使用浏览器识别或自行配置识别服务；后者单次录音最多 60 秒，音频不保存到作品。浏览器识别可能由浏览器厂商在线处理。
- 可朗读可见回复或正文开头，手动每次最多 2000 字；自动朗读默认关闭，开启后读新回复开头最多 400 字。可随时停止，开始说话也会停止播放。
- 外部识别或合成服务会接收相应音频或文本，可能收费；浏览器支持程度不同，不能据此假定全程离线。

## AI 为什么能衔接前文

生成按任务读取相关的已确认设定、人物、章纲、正文证据与记忆，并记录实际使用的来源。摘要帮助定位，原文用于核对；检索不代表模型每次都会看到全书。

作者改过正文之后，旧候选与旧审校可能失效。先核对本次生成依据，再处理过期内容，避免拿旧结果覆盖新手稿。

详见：[设定与人物](/features/longform/planning) · [大纲与正文](/features/longform/writing) · [连续性与改稿](/features/longform/continuity)。

## 深入使用长篇工具

- [文风学习与互动校准](/features/longform/style-learning)：语料、画像、注入开关与改稿反馈怎样配合。
- [项目参考与作品分析](/features/longform/references)：区分导入、研究、当前分析版本与写作引用。
- [角色驱动剧情](/features/longform/character-driven)：管理人物弧光方案，分别处理大纲采纳与当前参考。
- [伏笔、事实与认知](/features/longform/facts-foreshadowing)：区分计划、证据、角色所知和状态变化。
- [多世界、地点与地图](/features/longform/worlds-maps)：明确世界范围、空间关系与地图候选。

## 备份与派生

正文导出适合阅读、投稿和外部编辑；完整 JSON 用于项目备份，两者不能互相替代。[本地记忆工作区](/features/memory-workspace)可以把受支持内容保存成硬盘文件，但同步仍需作者检查确认。

长篇可显式[派生世界](/features/world-engine)。派生后原作品继续独立保存，双方后续修改不自动同步。

## 当前限制

工程规模验证不等于“一键生成百万字精品”。隐喻、未登记的伏笔、人物细微心理与文学判断仍需要作者参与。自由编排请查看[节点创作的预览边界](/features/nodes)。
