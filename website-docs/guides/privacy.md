# 隐私说明

## 作品与模型服务

作品主要保存在您的浏览器或已安装客户端中。不同浏览器、客户端和设备分别保存，请定期导出完整备份；备份可能包含私人作品，请妥善保管。

当您主动使用 AI 时，完成该操作所需的内容会发送给您配置的模型服务，相关处理受该服务商的协议与隐私规则约束。API 密钥请保存在模型设置中，不要写入作品、提示词、截图或反馈。

## 客户端用户协议 {#开发中的应用内反馈与使用统计}

安装版使用统一的《用户协议》，个人信息与隐私保护内容包含在协议正文中。请在首次启动时阅读，也可在通用设置中再次查阅。

同意客户端用户协议后，受支持的安装环境会发送必要的使用与故障信息，包括随机安装标识、构建版本、平台、活跃日期和脱敏错误类型/代码位置。活动按北京时间每天至多记录一次，普通网页和官网体验不启用这条客户端统计链路；它不读取作品正文、提示词或 API 密钥。

## 主动提交的反馈

应用内的问题与建议进入维护者私有收件箱。发送前请检查填写内容及自愿附带的故障摘要，不要包含私人作品或密钥。官网独立反馈表单会创建公开 GitHub Issue，提交前会提示其公开性质。

本机故障摘要用于排查问题，不是完整崩溃转储，也不能捕获每次异常退出。操作说明见[故障排查](/guides/troubleshooting)。

## 官网使用

官网为正常运行、维护安全和改善体验，处理必要的访问及技术信息，并可能使用第一方 Cookie 支持网站运行。官网不会读取创作工作区中的作品或 API 密钥。
