# 功能建议

请从实际使用场景出发描述当前问题，并说明希望如何改进。具体场景越清楚，越便于评估方案和优先级。

v4.0.2 可在“通用设置 → 问题与建议 → 功能建议”直接填写使用场景与希望的改进，检查后确认发送。应用内反馈进入维护者私有收件箱；下方网页表单创建公开 GitHub Issue。详见[反馈操作说明](/guides/troubleshooting#下载版的问题与故障反馈)与[隐私说明](/guides/privacy)。
