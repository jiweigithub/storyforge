# Bug 报告

请尽量提供可复现的问题描述、操作步骤和期望结果。提交截图或日志前，请先移除 API Key、Token、密码等敏感信息。

下载版可从“通用设置 → 问题与建议”先查看摘要，再带入此表单。检查“补充信息”后，只有你明确提交才会发送并进入公开 Issue。操作与捕获限制见[故障反馈说明](/guides/troubleshooting#下载版的问题与故障反馈)。

开发中的客户端还提供应用内“报告问题”和“功能建议”表单，无需发生崩溃即可提交。应用内反馈进入维护者私有收件箱；下方网页表单仍进入公开 Issue。详见[客户端反馈与统计](/guides/privacy#开发中的应用内反馈与使用统计)。
