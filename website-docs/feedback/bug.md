# Bug 报告

请尽量提供可复现的问题描述、操作步骤和期望结果。提交截图或日志前，请先移除 API Key、Token、密码等敏感信息。

v4.0.2 可在“通用设置 → 问题与建议 → 报告问题”填写并确认发送，应用内反馈进入维护者私有收件箱；“功能建议”也可直接提交，无需发生崩溃。故障摘要由您预览后选择是否附带，见[操作说明](/guides/troubleshooting#下载版的问题与故障反馈)。

**下方网页表单会创建公开 GitHub Issue。** 使用“带摘要打开官方反馈表单”时，提交前请检查“补充信息”，删除不想公开的内容。隐私说明见[客户端用户协议](/guides/privacy#开发中的应用内反馈与使用统计)。
