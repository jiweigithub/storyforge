# NW-2E 读取评测回执的磁盘故障保护

本次只修复本地离线评测的结果保存，不改模型、问题、预算、评分、生产投影或作者数据。没有新增真实模型调用；原未知输入没有重发。

此前运行器在生成结束后才写最终结果，磁盘写入失败时可能仅剩开始记录。现在开始前先检查至少 64 MiB 可用空间，并在每个新调用前复查。开始回执写入并同步后才允许模型工作；订阅桥发出提交意图通知时同步保存日志，之后才能发送 `turn/start`。提交意图仅说明本地准备发送，不表示服务端已接收或完成。

日志逐条带序号和校验值，分别记录用量、模型返回的完整原始文本和待提交的终态。完整文本先保存，再做输出格式与预算校验。最终文件先写入隔离暂存位置并同步，再以不能覆盖既有文件的方式发布；半截文件留作故障现场，不成为正式结果。写入失败会停止新派发，并将没有持久回执的尝试单列，避免错算为“从未调用”。

11 项新反例覆盖低空间拒绝、短写、禁止覆盖、结果发布时 ENOSPC、日志同步失败、半截日志、错身份/校验/顺序、输出大小与公开诊断；连同既有检查共 43 项 Node 测试。命令入口反例确认低空间时尚未启动模型通道，新增调用数为 0。另保存了 3 个使用真实文件操作和注入故障的探针，响应明确为合成测试内容，不能当真实模型证据。

4 文件/111 项检查与 v29 基线回读通过，226 个当前来源 hash 一致，原查询、IR 和领域投影观察不变。111 项中包含运行 43 项 Node 反例的包装检查，不重复相加。完整 lint、类型与静态检查通过；生产源码没有变化，未把以前的构建或排队中的完整 CI 说成本次增量已全部验证。

可用空间检查不是预留空间；其他进程仍可能在调用中占满磁盘，永久磁盘故障也可能阻止任何后续写入。日志仅供核对，不自动生成“成功”、重发调用或采纳内容。历史中断发生在本次日志机制之前，原来的 69 份成功、1 份失败、1 个未知尝试和 390 项未尝试仍保持；旧运行 484 个原始工件 hash 核对一致。
